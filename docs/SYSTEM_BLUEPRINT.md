# Levi Recovery Intelligence System (LRIS)

---

# Vision

The Levi Recovery Intelligence System (LRIS) is a simple, caregiver-friendly rehabilitation management application designed to help families, caregivers, and support workers coordinate long-term neurological rehabilitation.

The system is designed around the individual, not the diagnosis.

Its purpose is to organize care, support consistency, simplify caregiver onboarding, and help individuals work toward meaningful recovery goals.

---

# Design Philosophy

Every screen should answer one simple question.

---

## 🏠 Home

**What needs to be done today?**

---

## ❤️ Get to Know

**Who is this person?**

Provides caregivers with a personal introduction to the individual they are supporting.

This page is intended to build understanding, confidence, and connection before beginning care.

Suggested sections include:

- About Me
- My Story
- Recovery Goals
- Communication Tips
- What Works Best
- Things to Avoid
- Favourite Activities
- Family
- Motivation

---

## 📚 Therapy Library

**How do I do it?**

Provides instructions, videos, QR codes, printable guides, and rehabilitation activities organized by therapy category.

---

## 📝 Daily Log

**What happened today?**

Records completed activities, caregiver notes, observations, and daily progress.

---

## 👥 Caregiver

**Who completed the work?**

Provides caregiver management tools including hours worked, shift notes, requests, and caregiver resources.

---

# Core Principles

- Keep the interface simple.
- Every screen has one purpose.
- Build one complete workflow before expanding.
- Support the rehabilitation plan created by healthcare professionals.
- Reduce caregiver stress.
- Make onboarding simple.
- Focus on the person, not only the diagnosis.

---

# Version 1

Version 1 will include:

- 🏠 Home
- ❤️ Get to Know
- 📚 Therapy Library
- 📝 Daily Log
- 👥 Caregiver

---

# Long-Term Goal

The application should support multiple individuals without changing the software.

Only the person's information and rehabilitation plan should change.
