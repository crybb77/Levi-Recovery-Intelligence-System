# Brock String

## Purpose

The Brock String exercise is used to improve eye teaming, convergence, depth perception, and visual coordination.

---

## Goal

Complete three sessions each day:

- Morning
- Afternoon
- Evening

---

## Equipment Needed

- Brock String
- Chair (optional)

---

## Instructions

Detailed exercise instructions and QR code resources will be added here.

---

## Caregiver Tips

- Encourage slow, controlled movements.
- Allow short breaks if fatigue occurs.
- Record any unusual symptoms or observations.

---

## When to Stop

Stop the activity and notify the parent if significant discomfort, dizziness, nausea, headache, or double vision persists.
